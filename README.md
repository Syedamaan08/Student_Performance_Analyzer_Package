# Student Performance Analyzer Package

## Project Description
A modular Python package designed to validate student scores, calculate grades and GPA, and analyze overall class performance.

## Features
- Student score validation (0–100).
- Automatic grade and GPA calculation.
- Class average calculation.
- Pass percentage calculation.
- Identification of the top-performing student.
- Boundary case testing.
